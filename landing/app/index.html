How it works
Security without the jargon

fort speaks two languages: plain English for everyone, and raw terminal output for the curious.

🛡️

Score ring

A single 0–100% score across all checks. Green when you're protected, amber/red with clear next steps.

⚡

One-click & guided fixes

Turn on the safe things — firewall, screen lock, auto-updates and more — with a click. For settings macOS guards, fort shows clear steps and opens the right place.

📋

No dead ends

Every finding has a way forward: fix it, follow numbered steps, or pick a trusted tool. You're never left with a problem and no solution.

🔍

Technical details

Every check shows the raw command transcript — current value, expected value, and evidence. For the curious and the auditors.

🔒

Private & open source

No account, no telemetry — everything stays on your Mac (except update checks, which you can turn off). The checks are open source, so you can verify exactly what fort reads. Inspect the code →

🖥️

macOS-native

Built with SwiftUI. Respects your system appearance, uses Apple's system palette, and feels at home on your Mac.
