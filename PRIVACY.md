# Privacy

`fort` and its Claude Code plugin collect nothing.

- **No network calls.** The audit reads local system state and exits. Nothing about your machine is uploaded anywhere.
- **No telemetry, no analytics, no accounts.** There is no sign-up and no usage tracking.
- **Everything stays on your machine.** Audit results, the JSON output, and the HTML report (`fort-report.html`) are written locally. They are shared only if you choose to share them.
- **The plugin runs the local `fort` binary over your shell.** It adds no data collection of its own. It only sends commands to the tool you already installed.

Fixes change system settings on your own machine and are applied only after you approve them. They are never sent off the device.

Questions: open an issue at https://github.com/djadmin/fort/issues
